# Findings from the browser and work-policy milestone

Recorded 2026-10-07 before the final release gate; this is implementation and
focused validation evidence, not a claim that publication has occurred.

- A fixed 30-minute cutoff was too short for interacting core repairs. Allocate
  90 minutes or up to two hours for substantial work and match native, wrapper
  and CLI timers. Keep individual tests bounded and save early. Task deadlines
  are separate from subscription cooldowns and must not establish quota failure.
- Timed Bash reads cannot bound a blocking FIFO open that happens first.
  Admission now uses an already-open pipe and a complete bounded handshake.
  Partial replies refuse before any provider starts.
- Killing a Bash wrapper does not necessarily release the Python child holding
  a workflow lock. The actual holder now acknowledges release and is reaped;
  provider children do not inherit the release/control descriptors.
- Bash defers signal traps around a foreground command. Run and review now
  wait on their recorded provider in the shell, stop that owned tree on a signal
  and release the slot afterward. Mock checks cover both paths.
- One apparent reviewer-budget failure was a fixture mistake: an earlier test
  left the probe on another account group and passed it the reviewer's barrier.
  The run was permitted correctly. Restoring the shared group and asserting
  return2, no provider marker and a still-counted reviewer tests the intended rule.
  Failed fixtures now record and clean their own sessions and descendants.
- Git stdout can block before a process wait timeout. Worker file observation
  drains output under a deadline and cap, binds a confirmed root directory and
  cleans the exact owned group even when the Git parent has already exited.
- A real Gemini Pro High task completed through browser preview, approval,
  start-once, native verification, personal lead review and revision acceptance.
  Two Markdown files changed, both frozen checks passed, and no additional
  reviewer model was launched. The browser console candidate separately passed
  all nine frozen checks, including the Chromium journeys.
