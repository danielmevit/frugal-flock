# Interactive radial work map

The browser work map now has a bounded responsive canvas, zoom buttons and
percentage, Fit view, Reset 100%, mouse/touch dragging, keyboard controls and
Ctrl/Command-wheel zoom. Workers and their recorded tasks branch outward from
the Project hub. Manual camera position and scale persist through polls, view
switches and resizing, with exact task selection and bounded pagination intact.

Light and Dark use the approved neutral grayscale palette. The map remains
read-only and preserves existing output/file grants and failure recovery.
No external assets, dependency, AI call or backend permission was added.
Source for v0.5.4; published and installed v0.5.3 remain unchanged.
