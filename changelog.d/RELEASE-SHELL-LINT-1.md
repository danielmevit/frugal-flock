# RELEASE-SHELL-LINT-1

The release handshake writes its line to the owned policy descriptor on stdout. Foreground run and review store the project root for the exit trap in a shell variable, so a path that contains spaces or quotes stays data after the command returns. Closing an owned admission descriptor restores caller stderr, and a later diagnostic is still visible. Background pidfile removal and the TERM and INT reaping paths stay in place.
