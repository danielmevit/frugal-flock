CG-1: `agentteam init` no longer blocks on CodeGraph. Indexing ran inline in each new worktree with its output on /dev/null, so a six-worker init looked hung for minutes, left an idle indexer daemon behind per worktree, and caused one dispatch to silently never fire. Indexing is now detached (setsid + nohup), time-boxed by AGENTTEAM_CG_INDEX_TIMEOUT (default 600s), and skipped entirely unless the clone itself is indexed — an unindexed repo is the owner's decision, and six worktrees no longer each grow a database nobody asked for. Pinned by three selftest checks (skip / detach / time-box), each verified to fail against a mutant of the fix.
