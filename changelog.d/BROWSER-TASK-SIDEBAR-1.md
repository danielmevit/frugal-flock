# Selected task details beside the map

Clicking a task opens its details in the right-hand quarter of the map area
on wide screens. The map keeps the remaining three-quarters and fills the
area when selection is cleared. Smaller screens stack details below the map.
The desktop panel scrolls, wraps long names and preserves existing evidence,
selection and protected console actions. No backend or dependency changed.
Source for v0.5.4; the published/installed release remains v0.5.3.
