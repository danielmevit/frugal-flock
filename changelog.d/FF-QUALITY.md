M1 quality milestone, in progress (runtime 0.4.0, not an accepted release). `verify` now fails closed: missing scope or Validate lines are INCOMPLETE (exit 2), real failures exit 1, and with AGENTTEAM_AUTO_VERIFY a worker failure keeps its own exit while failed or incomplete checks make a successful run nonzero. Each worker/task gets a schema-versioned JSON result (`coord/results/`, read with `result`) with separate process, validation and review states bound to a revision of commit, base, task file and worktree contents, so any change marks old evidence stale and `ready_for_human_review` is never manufactured. `review` requires current passed validation and complete committed text material (binary, non-UTF-8 or over 300000 bytes refused), accepts exactly one standalone verdict from stdout, and exits 0/1/2. `agents --json` reports local availability without running agents or probing login/quota. `handoff` writes an atomic same-checkout context packet that is not a backup. Verify, review and handoff refuse assume-unchanged/skip-worktree index flags that hid edits from scope and review, and run keeps the worker's real exit, report and ledger line (`snapshot_failed`) when the post-run snapshot fails. Python 3 (standard library only) is now required for the evidence commands.
